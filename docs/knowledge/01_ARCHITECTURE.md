## 1.2 模块划分

| 模块 | 路径 | 功能 |
|------|------|------|
| **E203 Core** | `e203_hbirdv2/rtl/e203/` | RISC-V 32IMAC 处理器核 |

## 1.3 数据位宽

| 数据类型 | 位宽 | 说明 |
|---------|------|------|
| 权重 (Weight) | INT8 | 8位有符号定点数 |
| 激活值 (Activation) | INT8 | 8位有符号定点数 |
| 累加器 (Accumulator) | INT32 | 32位有符号整型 |

**原因**: E203 是 32 位处理器，INT8 匹配性好，INT32 避免溢出。

## 1.4 PE 阵列结构

```
         Column 0   Column 1   Column 2   Column 3
        ┌────────┬────────┬────────┬────────┐
Row 0   │  PE00  │  PE01  │  PE02  │  PE03  │ ← 行输入: 激活值
        ├────────┼────────┼────────┼────────┤
Row 1   │  PE10  │  PE11  │  PE12  │  PE13  │
        ├────────┼────────┼────────┼────────┤
Row 2   │  PE20  │  PE21  │  PE22  │  PE23  │
        ├────────┼────────┼────────┼────────┤
Row 3   │  PE30  │  PE31  │  PE32  │  PE33  │
        └────────┴────────┴────────┴────────┘
                  ↑
           列输入: 权重值
           
           ↑ 累加器输出 (INT32)
```

**并行度**: 16 个 PE 同时计算 = 一次 4×4 矩阵乘法

## 1.5 数据流: Output Stationary (OS)

> **选择原因**: 适合固定输出尺寸，累加器本地化，减少数据搬运

```
权重加载阶段:
  → 4个时钟周期，每周期1列 (4×32bit=128bit)
  
激活加载阶段:
  → 4个时钟周期，每周期1行 (4×32bit=128bit)
  
计算阶段:
  → 16个PE同步执行 multiply-accumulate (MAC)
  → 部分和保留在PE内
  
结果读出:
  → 1个时钟周期读出最终累加结果
```

## 1.6 关键设计决策

| 决策 | 选择 | 备选方案 | 选择原因 |
|------|------|---------|---------|
| PE 阵列规模 | 4×4 | 2×2, 8×8 | 平衡面积与并行度 |
| 数据流 | Output Stationary | Row Stationary | 适合固定输出场景 |
| NICE 协议 | Request/Response | ICB 内存访问 | 简化调试，降低风险 |
| 累加器位宽 | INT32 | INT16 | 防止多通道累加溢出 |
| 权重/激活精度 | INT8 | FP16 | E203 嵌入式场景，INT8 够用 |
