# PE 阵列微架构

> 版本: 1.0 | 更新: 2026-03-26

## 3.1 Processing Element (PE) 结构

```
         8bit          8bit
      Weight(W)    Activation(D)
           │             │
           ▼             ▼
        ┌──────────────────┐
        │   multiplier      │ ← INT8 × INT8 = INT16
        └────────┬─────────┘
                 │
                 ▼
        ┌──────────────────┐
        │   accumulator    │ ← INT16 + INT32 = INT32
        │   (Acc[31:0])    │
        └────────┬─────────┘
                 │
                 ▼
            Result[31:0]
```

### 单个 PE 单元功能

```verilog
// 核心计算
Acc = Acc + (W * D);  // MAC 操作
```

**关键特性**:
- 有符号 INT8 乘法 → INT16 中间结果
- INT32 累加器防止溢出
- 累加器本地保留（Output Stationary）

## 3.2 4×4 PE 阵列

```
              Weight Columns (从左到右加载)
         W[0]    W[1]    W[2]    W[3]
        ┌────────┬────────┬────────┬────────┐
   D[0] │  PE00  │  PE01  │  PE02  │  PE03  │ ← Row 0 激活
        ├────────┼────────┼────────┼────────┤
   D[1] │  PE10  │  PE11  │  PE12  │  PE13  │ ← Row 1 激活
        ├────────┼────────┼────────┼────────┤
   D[2] │  PE20  │  PE21  │  PE22  │  PE23  │ ← Row 2 激活
        ├────────┼────────┼────────┼────────┤
   D[3] │  PE30  │  PE31  │  PE32  │  PE33  │ ← Row 3 激活
        └────────┴────────┴────────┴────────┘

        ↑                              ↑
   列0权重                          列3权重
```

### 数据对应关系

| PE | 权重索引 | 激活索引 | 计算内容 |
|----|---------|---------|---------|
| PE00 | W[0] | D[0] | W[0]×D[0] |
| PE01 | W[1] | D[0] | W[1]×D[0] |
| PE02 | W[2] | D[0] | W[2]×D[0] |
| PE03 | W[3] | D[0] | W[3]×D[0] |
| PE10 | W[0] | D[1] | W[0]×D[1] |
| ... | ... | ... | ... |

**一次计算完成 4×4 矩阵乘法的一行输出**

## 3.3 串行加载 → 并行计算

> NICE 总线是 32bit，但 PE 阵列需要 128bit 权重 + 128bit 激活

### 加载时序

```
权重加载 (4 cycles):
  Cycle 0: W[0] → 列0 → PE00,PE10,PE20,PE30
  Cycle 1: W[1] → 列1 → PE01,PE11,PE21,PE31
  Cycle 2: W[2] → 列2 → PE02,PE12,PE22,PE32
  Cycle 3: W[3] → 列3 → PE03,PE13,PE23,PE33

激活加载 (4 cycles):
  Cycle 0: D[0] → 行0 → PE00,PE01,PE02,PE03
  Cycle 1: D[1] → 行1 → PE10,PE11,PE12,PE13
  Cycle 2: D[2] → 行2 → PE20,PE21,PE22,PE23
  Cycle 3: D[3] → 行3 → PE30,PE31,PE32,PE33

计算 (1 cycle):
  → 16 个 PE 同时执行 MAC
  → 每个 PE 输出 1 个部分和
```

### 为什么这样设计?

| 设计选择 | 原因 |
|---------|------|
| 串行加载 | NICE 总线 32bit，PE 阵列 128bit |
| 4×4 阵列 | 平衡面积(16 PE)与E203主频 |
| INT8 | 嵌入式场景够用，节省资源 |
| OS 数据流 | 累加器本地保留，减少访存 |

## 3.4 数据流对比

| 数据流 | 权重移动 | 激活移动 | 累加器位置 | 适合场景 |
|--------|---------|---------|-----------|---------|
| **Output Stationary** | 列方向 | 行方向 | PE 内部 | 固定输出尺寸 ✅ |
| Row Stationary | 列方向 | 对角线 | 行方向 | 低功耗 |
| Weight Stationary | 固定 | 行方向 | 列方向 | 权重复用 |
| Systolic Array | 固定 | 固定 | 移动 | 高性能 |

**本项目选择 Output Stationary**: 适合 CNN 卷积层输出尺寸固定的场景。

## 3.5 资源占用估算

| 资源 | 数量 | 位宽 | 说明 |
|------|------|------|------|
| 乘法器 | 16 | 8×8 | 理论 16 个 |
| 加法器 | 16 | 32bit | 累加用 |
| 寄存器 (累加器) | 16 | 32bit | Acc |
| 权重 Buffer | 4 | 32bit | 存储当前列权重 |
| 激活 Buffer | 4 | 32bit | 存储当前行激活 |

**FPGA 资源评估** (Artix-7 xc7a35t):
- LUT: ~500 (估计)
- FF: ~800 (估计)
- DSP: 16 (如果用 DSP 块实现乘法)

## 3.6 计算时序状态机

```verilog
IDLE:
    等待 COMP 信号
    
LOAD_W:
    接收 WLOAD，每4次循环填满权重列寄存器
    
LOAD_D:
    接收 DLOAD，每4次循环填满激活行寄存器
    
COMPUTE:
    所有 PE 同时 MAC
    累加结果保留在 PE 内
    
READ:
    RSTAT 读取累加结果
    
CLEAR:
    清零所有 PE 累加器
```
