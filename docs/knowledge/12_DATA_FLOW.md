# 数据流策略

> 版本: 1.0 | 更新: 2026-03-26

---

## 12.1 什么是数据流

数据流 (Dataflow) 描述了**数据在加速器内如何流动和复用**。

选择合适的数据流可以：
- 减少内存访问
- 降低功耗
- 提高计算效率

---

## 12.2 四种经典数据流

### 1. Output Stationary (OS) ✅ 本项目采用

**特点**: 每个 PE 内的累加器保持不动，输出值固定在 PE 中。

```
PE[i][j] 内:
  Acc[i][j] = Acc[i][j] + W[j] × D[i]
  (累加器不动，乘法结果流入累加)
```

**优点**:
- 适合固定输出尺寸的 CNN 层
- 累加器本地化，减少数据移动
- 功耗低

**缺点**:
- 不够灵活，换层需清零

---

### 2. Row Stationary (RS)

**特点**: 输入行在 PE 间复用，沿对角线移动。

```
数据移动:
  Row 0 → 对角线方向
  Row 1 → 对角线方向
  ...
  每个权重被多行复用
```

**优点**:
- 最大化数据复用
- 适合窄 tall 形状的层

**缺点**:
- 控制复杂

---

### 3. Weight Stationary (WS)

**特点**: 权重固定在 PE 内，激活值移动。

```
每个 PE 持有一列权重:
  PE[0]: W[0] 固定
  PE[1]: W[1] 固定
  ...
  
  激活值 D[0], D[1], ... 依次流入
```

**优点**:
- 权重只加载一次
- 适合权重复用场景

**缺点**:
- 累加器需要移动

---

### 4. Systolic Array (SA)

**特点**: 数据像心跳一样脉动流动，PE 本身几乎无存储。

```
时钟 0: W[0] → PE[0] → PE[1] → PE[2]
时钟 1:       W[0]   → PE[0] → PE[1] → PE[2]
时钟 2:             W[0]   → PE[0] → PE[1] → PE[2]
```

**优点**:
- 规则，易于 VLSI 实现
- 时钟驱动，无需复杂控制

**缺点**:
- 需要双倍缓冲

---

## 12.3 数据流对比

| 数据流 | 权重复用 | 激活复用 | 累加器位置 | 控制复杂度 |
|--------|---------|---------|-----------|-----------|
| **OS** | 列内 | 行内 | PE 内部 ✅ | 低 |
| RS | 高 | 中 | 行方向 | 中 |
| WS | ✅ 极高 | 低 | 列方向 | 中 |
| SA | 中 | 中 | 移动 | 低 |

---

## 12.4 为什么选择 OS？

| 因素 | OS | 其他 |
|------|-----|------|
| CNN 层适配 | 适合主流层 | 部分层效率低 |
| 控制逻辑 | 简单 | 复杂 |
| 寄存器需求 | 16 × 32bit | 更高 |
| 本项目实现 | ✅ 已有 | - |

## 12.5 本项目数据流详解

```
Step 1: 权重加载 (列优先)
  Cycle 0: W[0] → 列0所有PE → PE[0][j] 保持 W[0]
  Cycle 1: W[1] → 列1所有PE → PE[1][j] 保持 W[1]
  Cycle 2: W[2] → 列2所有PE → PE[2][j] 保持 W[2]
  Cycle 3: W[3] → 列3所有PE → PE[3][j] 保持 W[3]

Step 2: 激活加载 (行优先)
  Cycle 4: D[0] → 行0所有PE → 计算 W[j]×D[0]，加到 Acc[j]
  Cycle 5: D[1] → 行1所有PE → 计算 W[j]×D[1]，加到 Acc[j]
  Cycle 6: D[2] → 行2所有PE → 计算 W[j]×D[2]，加到 Acc[j]
  Cycle 7: D[3] → 行3所有PE → 计算 W[j]×D[3]，加到 Acc[j]

Step 3: 结果读出
  Cycle 8: RSTAT → 读取每个 PE 的 Acc 值
```

**总周期**: ~10 cycles (含控制开销)
