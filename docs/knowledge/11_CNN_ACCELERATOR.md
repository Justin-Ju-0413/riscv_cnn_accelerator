## 11.1 CNN 基础

卷积神经网络 (CNN) 的核心操作是**卷积**：

```
Output[y,x] = Σᵢ Σⱼ Input[y+i, x+j] × Kernel[i,j]
```

**直观理解**:
- 一个窗口（Kernel）在输入图上滑动
- 每个位置做"乘-加"运算
- 窗口滑完，得到输出特征图

---

## 11.2 卷积计算示例

```
输入 (3×3):
  [1, 2, 3]
  [4, 5, 6]
  [7, 8, 9]

卷积核 (2×2):
  [1, 0]
  [0, 1]

输出 (2×2):
  [1*1+2*0+4*0+5*1, 2*1+3*0+5*0+6*1]   [7,  11]
  [4*1+5*0+7*0+8*1, 5*1+6*0+8*0+9*1] = [19, 23]
```

---

## 11.3 为什么需要硬件加速？

**纯软件的问题**:
- 一个卷积层可能有上百万次乘法累加
- CPU 顺序执行太慢
- 嵌入式场景功耗敏感

**硬件加速的优势**:
- 并行计算（多个 PE 同时工作）
- 数据复用（减少内存访问）
- 专用电路（比通用 CPU 更快更省电）

## 11.4 加速器常见指标

| 指标 | 说明 |
|------|------|
| **TOPS** | 每秒万亿次操作 (Tera Operations Per Second) |
| **MAC/s** | 乘法累加次数/秒 |
| **FPS** | 每秒处理帧数 (用于图像) |
| **功耗** | 瓦特 (W) |
| **能效** | TOPS/W |

## 11.5 定点量化

| 格式 | 位宽 | 范围 | 用途 |
|------|------|------|------|
| FP32 | 32bit | ~10³⁸ | 训练/参考模型 |
| FP16 | 16bit | ~10⁴ | 训练加速 |
| **INT8** | 8bit | -128~127 | **嵌入式推理** ✅ |
| INT4 | 4bit | -8~7 | 极致压缩 |

**INT8 选择原因**:
- E203 是 32bit 处理器，INT8 匹配性好
- 功耗和面积比 FP16 低很多
- CNN 对噪声容忍度高

## 11.6 常见加速器架构

### Systolic Array (脉动阵列)

```
        W[0]  W[1]  W[2]  W[3]
          │     │     │     │
    D[0] →[+]→[+]→[+]→[+]
          ↓     ↓     ↓     ↓
    D[1] →[+]→[+]→[+]→[+]
          ↓     ↓     ↓     ↓
    D[2] →[+]→[+]→[+]→[+]
          ↓     ↓     ↓     ↓
    D[3] →[+]→[+]→[+]→[+]
```

### PE Array (处理元阵列)

```
  每个 PE 包含:
  ┌────────┐
  │ Multiply│ ← 8×8乘法
  │   +    │
  │ Accum  │ ← 32位累加
  └────────┘
  
  4×4 排列，共享权重/激活总线
```

## 11.7 与 E203 集成的挑战

| 挑战 | 本项目解决方案 |
|------|---------------|
| 带宽限制 | NICE 32bit 总线，分 4 次加载 128bit |
| 指令编码 | 自定义 5 条 NICE 指令 |
| 内存访问 | 权重/激活需 CPU 预加载到缓冲区 |
| 同步 | req/resp 握手协议 |
