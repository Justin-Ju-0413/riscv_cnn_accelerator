## 10.1 RISC-V 简介

RISC-V 是一个开源的 RISC 指令集架构 (ISA)，由 UC Berkeley 设计。

**特点**:
- 开源免费，无版权限制
- 模块化设计（基础 + 扩展）
- 支持 32/64/128 位
- 广泛应用于学术和工业

**常见扩展**:

| 扩展 | 说明 |
|------|------|
| M | 整数乘除法 |
| A | 原子操作 |
| F | 单精度浮点 |
| C | 压缩指令 |
| I | 基本整数指令 (必需) |

## 10.2 E203 处理器核

**Hummingbird E203** 是 Nuclei 公司维护的低功耗 RISC-V 处理器核。

### 关键参数

| 参数 | 值 |
|------|---|
| ISA | RV32IMAC / RV32EMAC |
| 流水线 | 2 级 |
| 模式 | Machine Mode only |
| 调试 | RISC-V Debug 0.11 |
| 特色 | NICE 协处理器接口 |

### 架构图

```
┌──────────────────────────────────────┐
│              E203 Core               │
│                                      │
│  IFU ────────────────────────┐       │
│  (Fetch Unit)                 │       │
│                              ▼       │
│  ┌─────────────────────────────────┐ │
│  │          EXU (Execute)          │ │
│  │   Decode → Execute → WriteBack  │ │
│  └─────────────────────────────────┘ │
│                              │       │
│  LSU ────────────────────────┘       │
│  (Load/Store Unit)                   │
│                              │       │
│  BIU ──────────────────────── │       │
│  (Bus Interface)              │       │
└───────────────────────────────┼───────┘
                                │
              ┌─────────────────┼─────────────────┐
              │                 │                 │
           ITCM              DTCM              NICE
        (指令存储)          (数据存储)        (协处理器)
```

## 10.3 内存布局

| 区域 | 地址 | 大小 | 说明 |
|------|------|------|------|
| ITCM | 0x8000_0000 | 64KB | 指令紧耦合存储 |
| DTCM | 0x9000_0000 | 64KB | 数据紧耦合存储 |
| CLINT | 0x0200_0000 | 64KB | 核内中断控制器 |
| PLIC | 0x0C00_0000 | 16MB | 平台中断控制器 |
| GPIO | 0x1000_0000 | - | 外设 |

## 10.4 为什么选 E203？

| 因素 | E203 | ARM Cortex-M | 其他 RISC-V |
|------|------|-------------|------------|
| 开源 | ✅ 完全开源 | ❌ 需授权 | 部分开源 |
| NICE 接口 | ✅ 原生支持 | ❌ 无 | 部分支持 |
| 功耗 | 极低 | 低 | 差异大 |
| 文档 | 中文友好 | 英文 | 差异大 |
| 教学资源 | 丰富 | 丰富 | 一般 |

---

## 10.5 本项目选择 E203 的原因

1. **开源 + NICE**: 最适合做协处理器扩展研究
2. **中文社区**: 蜂鸟 E203 在国内教学应用广泛
3. **FPGA 支持**: 有成熟的 FPGA 开发板支持 (DDR200T, MCU200T)
4. **SDK 支持**: Nuclei 提供完整 SDK
