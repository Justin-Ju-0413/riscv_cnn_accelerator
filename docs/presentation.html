Key Breakthrough

NICE Encoding Fix

The Problem

funct3 was used as the instruction selector

Root Cause

E203 NICE uses bits [14:12] for xd / xs1 / xs2, not funct3. The selector must live in funct7.

The Fix

Selector moved to funct7 · Confirmed RSTAT = 320

→ Full SoC simulation now reproduces expected behavior
